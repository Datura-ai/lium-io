`ContainerDeleteOnNodeLeftRequest` (backend → validator; a `ContainerDeleteRequest` with the required `create_command_id`) and `FailedContainerErrorCodes.NotTheNodeLeft`: the delete of a moved pod's container on the node it left. The validator removes, by the inspected ID, only the pod's container labelled with this pod and `create_command_id` (`io.lium.create_command_id`); anything else under the name is kept and answered `NotTheNodeLeft`. The delete is sent before the replacement create, which gets another create id, so the label alone tells the container the pod left from any later one. It refuses while a create of the pod runs. `ContainerDeleted.command_id` (optional, default empty): that delete's `command_id`, echoed (also on its `FailedContainerRequest`); empty for any other delete and from older validators. A validator that does not know the type refuses the message.
