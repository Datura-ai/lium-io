`ResetVerifiedJobRequest.unrented_only` (optional, default false): the check that cleared the verified job meant it for an idle node only; the backend then applies the reset only while no customer pod runs on the node, and otherwise closes the node to new rentals until a full check passes. A field of its own, not inside the reset's evidence, so no evidence size can drop it. `ExecutorSpecRequest.idle_checks_passed` (optional): the check_ids of those idle-only checks that this cycle ran in full on the node and passed (a skipped run is not listed); the backend lifts that hold only when the check that failed is listed.
