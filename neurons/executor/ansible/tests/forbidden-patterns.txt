# Patterns that must NOT appear in this tree, and three that MUST.
#
# THIS FILE LIVES OUTSIDE EVERY SEARCH SCOPE ON PURPOSE. It contains every one
# of the literals it bans, so a checker that searched its own pattern list would
# match itself. The danger there is not a red build — it is an implementer
# narrowing the search until it goes green, and quietly deleting the enforcement.
#
# The role READMEs are excluded for the same reason: they are REQUIRED to quote
# strings like --reset-with-sbr and mpa_registration.log as do-not-do-this
# documentation. So is the whole tests/ tree.
#
# FORMAT:  <sense>\t<kind>\t<scope>\t<pattern>\t<why>
#
#   sense   deny | require
#   kind    fixed  — a literal string (grep -F)
#           regex  — an extended regular expression (grep -E)
#   scope   tree      — roles/*/{tasks,files,templates}/, group_vars/, site.yml,
#                       and bootstrap.sh
#           bootstrap — bootstrap.sh alone
#           commands  — group_vars/all/commands.yml alone
#           groupvars — group_vars/**
#           ci        — .github/workflows/test.yml and qemu-2604-compile.yml
#           all       — tree plus ci
#
# Scope is per-pattern because the rules genuinely differ. `|| true` inside a
# fact collector means "absent is a valid answer and I handle it below", which is
# correct and load-bearing; the same two characters in a CI step silently discard
# the exit code the step exists to check. Banning it everywhere would force
# rewrites that make the collectors worse, and banning it nowhere would let the
# original defect back in.

# --- GPU resets that made things worse -----------------------------------------
deny	fixed	all	--reset-with-sbr	On au1 this left the GPU [broken, cfg space working] with the PCIe data link down (DLLLA:0). Wedged GPUs are recovered by PCIe hot-remove plus rescan, and by nothing else.
deny	fixed	all	--recover-broken-gpu	Failed to bring back the GPU that --reset-with-sbr broke.
deny	fixed	all	--reset-with-flr	Failed to bring back the GPU that --reset-with-sbr broke.

# --- process matching that killed live sessions --------------------------------
deny	fixed	all	pgrep -f	Matching a pattern that also appears in your own command line. `pkill -f listen.py` matched the ssh command carrying it and killed the session, twice. Match /proc/<pid>/comm instead.
deny	fixed	all	pkill -f	Same defect, with teeth.

# --- signals that lie -----------------------------------------------------------
deny	fixed	all	mpa_registration.log	Reported "registration is completed successfully" on the BROKEN host and the healthy one alike. Read the pck_cert row count in pckcache.db.
deny	fixed	all	platforms_registered	0 is normal on a healthy host, so this is not the field to read.
deny	fixed	all	lium-cvm.sh check	`check` looks for qemu-system-x86_64 on PATH while the launcher uses /etc/dstack/client.conf, so it reports a false MISSING on a correctly configured host. Read client.conf directly.

# --- apt and modprobe forms that silently do nothing ---------------------------
deny	fixed	all	sgx-setup	Lives in Ubuntu universe, not Intel's repository. Naming it aborts the WHOLE apt transaction, so every other package silently fails to install.
deny	fixed	all	modprobe vfio_iommu_type1 vfio-pci	The second argument is read as a module PARAMETER: "unknown parameter 'vfio-pci' ignored". Load them as separate modules.

# --- secrets on an argv ---------------------------------------------------------
deny	regex	all	curl[^|]*-H[[:space:]]+["']	no_log hides a value from Ansible's output and does NOTHING about /proc/<pid>/cmdline, which any local user can read with ps aux. Use the uri module, or a 0600 header file removed in an always: block.

# --- assertions that are silently inert ----------------------------------------
deny	fixed	ci	|| true	Discards the exit code of the very step that exists to check it. Two of these once kept a merge gate green while it proved nothing.
deny	fixed	bootstrap	|| true	Same, in the entry point. bootstrap.sh's exit code is a contract: CI compares it against --print-expected-preflight-rc and a provider's automation gates on it. Swallowing a status here makes that constant meaningless. Deliberately scoped separately from the fact collectors under roles/*/files/, where `$(cmd || true)` means "absent is a valid answer and I handle it below".
deny	regex	ci	^[[:space:]]*![[:space:]]+grep	INERT under bash -e: POSIX says set -e is ignored for a command preceded by `!`, and GitHub Actions' default shell is `bash -e {0}`. This is the `|| true` defect wearing a different hat, and it shipped once already. Write an explicit `if grep ...; then echo FAIL; exit 1; fi`.
deny	regex	ci	^[[:space:]]*![[:space:]]+test	Same. The anchoring is deliberate: it targets the BARE command form, which is the inert one. `if ! command -v foo; then ...; else ...; fi` is safe, because an if condition is exempt from set -e by design and both branches are handled. Do not "improve" this into an unanchored pattern — that false-positives on the safe form, which is how someone ends up narrowing the search until it goes green.

# --- things that MUST be present -----------------------------------------------
# Scoped to where the value has to LIVE, not merely be mentioned. At tree scope
# these were satisfied by a runtime error message that quotes the flag, so
# deleting the real one went unnoticed.
require	fixed	commands	--setenv=HOME=	systemd-run starts with HOME UNSET. Without this the build script's `set -u` dies at line 3 while the unit goes inactive within seconds and looks finished with nothing built.
require	fixed	groupvars	17950	The PLATFORM_MANIFEST body length Intel accepts. The raw efivar is 17954 bytes — a 4-byte version+size header plus this body — and POSTing the 17954-byte blob returns 400 InvalidPlatformManifest.
require	fixed	commands	--gpu-bdf	A bare --query-cc-mode only LISTS devices and reports nothing about the one you asked about.
require	fixed	tree	exec >"$LOG_DIR/qemu-build.log"	The build script must write the file the role waits on. systemd-run supplies no redirection, so without this the log never exists and the role waits out its full 3600 s timeout AFTER a build that succeeded.
deny	fixed	ci	tee /var/log/lium-cvm/qemu-build.log	The compile job must NOT supply the build script's log redirection for it. Doing so kept the job green while the real path — the role waiting on a file nothing wrote — was broken, which is the opposite of what a de-risk job is for.
